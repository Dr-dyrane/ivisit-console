# iVisit Console Documentation

## RBAC Documentation Structure

We have consolidated the RBAC (Role-Based Access Control) documentation into two authoritative files to reduce confusion.

### 1. 🏗️ Architecture & Model
**File:** [`RBAC_Architecture.md`](./RBAC_Architecture.md)
- **Purpose:** Defines the conceptual model, including Roles, Scopes, and the "Apple Standard" philosophy.
- **Use for:** Understanding *how* permissioning works conceptually (e.g., "What is an Org Admin vs. Platform Admin?").

### 2. ✅ Implementation Status
**File:** [`RBAC_Implementation_Status.md`](./RBAC_Implementation_Status.md)
- **Purpose:** Tracks the actual state of the codebase. Lists completed scenarios, applied patterns, and recent fixes.
- **Use for:** Checking what is currently built, referencing code patterns (scoping snippets), and auditing completed tasks.

---
*Note: Older planning documents (`RBAC_EXECUTION_PLAN`, `RBAC_MASTER_ARCHITECTURE`, etc.) have been archived/deleted to prevent drift.*
